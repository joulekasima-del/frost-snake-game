# Frost Snake

A small responsive snake game prototype inspired by an icy arcade visual style.

## Open the game

Open `index.html` in a browser, or serve the folder with any simple static web server.

## Controls

- Desktop: arrow keys or WASD
- Pause or resume: Space, or the Pause button
- Mobile: swipe on the board or use the on-screen direction buttons
- Restart: Restart button

## Current gameplay

- Eat glowing frost orbs to score points.
- Every five orbs increases the level and speed.
- Avoid walls, blue ice blocks, and the snake body.
- Best score is saved in the browser on the same device.
